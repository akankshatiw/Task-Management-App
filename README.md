# Task Management Web Application

A simple, responsive and user-friendly Task Management Web Application built using HTML, CSS and JavaScript. This application helps users organize their daily activities, track task completion and manage their productivity efficiently.

## 🚀 Features

- **Add Tasks:** Create new tasks by entering a task description.
- **Delete Tasks:** Remove tasks that are no longer required.
- **Mark as Completed:** Mark tasks as completed using a checkbox or Complete button.
- **Undo Completed Tasks:** Move completed tasks back to pending status.
- **Task Summary:** View total, completed and pending task counts.
- **Local Storage:** Automatically save tasks in the browser so they remain available after refreshing the page.
- **Responsive Design:** Access the application on desktop and mobile devices.

## 🛠️ Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and responsive user interface.
- JavaScript – Application functionality and DOM manipulation.
- Browser Local Storage – Persistent storage of task data.

## 💻 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/akankshatiw/Task-Management-App.git
```

### 2. Navigate to the Project Directory

```bash
cd Task-Management-App
```

### 3. Open the Project

Open the project folder in Visual Studio Code.

### 4. Run the Application

- Install the Live Server extension in VS Code.
- Open `index.html`.
- Right-click and select **Open with Live Server**.
- The application will open in your default browser.
